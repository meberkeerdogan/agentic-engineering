# 0001. Record Architecture Decisions

Date: 2026-07-01

## Status

Accepted

## Context

Agent Loops will involve choices about schema design, runtime behavior, safety boundaries, supported tools, skill formats, and contribution standards. These decisions should be visible to future contributors.

## Decision

Use lightweight architecture decision records in `docs/adr/`.

Each decision record should include:

- title
- date
- status
- context
- decision
- consequences

## Consequences

- Contributors can understand why major choices were made.
- Design discussion can move from repeated debate to documented tradeoffs.
- The repository gains a durable project memory.
